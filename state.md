## DECISIONS

- **One lot = one commit**, conventional commits in English, ≤400 changed LOC
  per commit excluding the regenerated bundle. `npm run check` green before each
  commit; `npm run client` before each commit that touches `src/client/**`.
- **New logic goes into pure, testable modules** imported by the host; the host
  file is not grown further except for the wiring lines.
- **`src/client.js` is never hand-edited**: it is regenerated by
  `npm run client` and committed with the lot that changed its sources.
- **Backward compatibility is mandatory**: a persisted `state.json`/journal
  written by 0.1.0 must still load. Every new field is optional-on-read and
  normalised at the boundary; migrations are pure functions.
- **Conservative defaults do not move.** Configurable ≠ different: the default
  numbers of 0.1.0 stay identical so an upgrade changes no behaviour silently.
- **No new test replaces an existing one.** If a correction contradicts an
  existing test, stop and report instead of editing that test (none so far).
- **Client decoding is tolerant, host emitting is strict.** The host publishes
  the versioned object; the client accepts the versioned object, the legacy
  array, and anything else as empty.
- **`null` = unlimited, `0` = a real freeze** for the new concurrency knobs
  (never the other way round: inverting `0` would turn an operator's freeze into
  an unlimited grant), the documented default stays the current finite number,
  and a named hard ceiling (`CONCURRENCY_HARD_CEILING`) only guards keying
  mistakes.

### Decisions taken with the operator

- The 0.1.0 ceilings (2 concurrent, 6 starts/hour) are lifted ONCE to `null`
  (audited `load_model_migrated`); a deliberate non-default value is kept. The
  hourly field survives as an advanced valve and an explicit `null` now means
  "no rate limit".
- The machine guard never blocks everything (floored at one, raw figure
  published); the token pool may reach zero and is published as `blocked`.
- `maxDelegationsPerHour: 0` keeps meaning zero (an existing 0.1.0 test pins it);
  the UI floor of one applies to configured ceilings, and Pause is the real brake.

### The one production incident of this round

The first host wiring read `ctx.tokenMeter` as a PROPERTY. A Cordis context
throws on an undeclared service, the throw escaped a `/state` route promise and
took the Host down while the plugin was live. Fixed by reading optional services
through `ctx.get(name)` (inject-free) in `tokenMeterOf()`, and by guarding the
direct read in `src/executors/dsh.js`. It also migrated the operator's real
`state.json` (the plugin was live): the two ceilings there are now `null` and the
audit trail carries the `from` values.
