     `superagentPublicOf()`.
   - Client reads an ARRAY: `src/client/core.js:73-76`

   - Same assumption in `src/client/ui/hierarchy.js:495`

## DECISIONS

- **One lot = one commit**, conventional commits in English, ≤400 changed LOC
  per commit excluding the regenerated bundle. `npm run check` green before each
  commit; `npm run client` before each commit that touches `src/client/**`.
- **New logic goes into pure, testable modules** imported by the host; the host
  file is not grown further except for the wiring lines.
- **`src/client.js` is never hand-edited**: it is regenerated by
  `npm run client` and committed with the lot that changed its sources.
- **Backward compatibility is mandatory**: a persisted `state.json`/journal
  written by 0.1.0 must still load. Every new field is optional-on-read and
  normalised at the boundary; migrations are pure functions.
- **Conservative defaults do not move.** Configurable ≠ different: the default
  numbers of 0.1.0 stay identical so an upgrade changes no behaviour silently.
- **No new test replaces an existing one.** If a correction contradicts an
  existing test, stop and report instead of editing that test (none so far).
- **Client decoding is tolerant, host emitting is strict.** The host publishes
  the versioned object; the client accepts the versioned object, the legacy
  array, and anything else as empty.
- **`null`/`0` = unlimited** for the new concurrency knobs, but the documented
  default stays the current finite number, and a named hard ceiling
  (`CONCURRENCY_HARD_CEILING`) only guards keying mistakes.
